Exporter mes données

Vous avez la possibilité d’exporter tout ou partie de vos observations dans le format de votre choix. Cela vous permet de regrouper plusieurs cycles dans un même fichier. Les formats disponibles sont :

  • NFP : ce format vous permet d’exporter vos données afin de pouvoir les réimporter ultérieurement dans l’application. Il est également compatible avec d’autres applications si vous souhaitez migrer vos données.
  • PDF : ce format facilite le partage visuel de vos cycles avec vos moniteurs ou instructrices.
  • CSV : ce format vous permet d’importer vos cycles dans LibreOffice ou Microsoft Excel pour une analyse plus détaillée.

Exporter au format




À la fin de chaque cycle d’au moins 5 jours, vous recevez par e-mail (et sur votre 2e adresse si vous en avez indiqué une) l’export de ce cycle aux formats PDF, CSV et NFP. Décochez cette case pour ne plus recevoir ces e-mails.


Comme demandé par la RGPD, vous avez aussi la possibilité d’exporter l’ensemble des données liées à votre compte. Cet export sera au format CSV.





Importer mes données

Vous pouvez réinjecter dans votre tableau un fichier au format NFP: un export de cette application, ou l’export d’une autre application compatible. Les cycles du fichier s’ajoutent à ceux que vous avez déjà.




Quand une date du fichier est déjà renseignée dans votre tableau: case décochée (par défaut), votre journée est conservée telle quelle et celle du fichier est ignorée; case cochée, la journée du fichier remplace entièrement la vôtre (glaire, sensations, observations, température, commentaire, union…) et votre version actuelle est définitivement perdue.


Vérifier le fichier n’écrit rien: la simulation vous dit ce que l’import ferait, quels jours sont déjà renseignés, et ce qui ne peut pas être repris.

Authentification multifacteur

La double authentification est une méthode de sécurité qui demande à l'internaute de fournir deux types d'informations différentes pour prouver son identité. Ainsi, pour accéder à votre tableau il vous sera demandé de saisir votre mot de passe et un code temporaire disponnible dans une applications sur votre téléphone. Ce système permet de renforcer la sécurité de vos données personnelles en cas de fuite ou de vol de votre mot de passe ou d'un mot de passe trop faible (entre autres).

Configurez votre application d'authentification multifacteur. Vous n'avez pas encore d'application de ce type? téléchargez FreeOTP.

option 2: si vous êtes sur votre ordinateur, scannez le QR code ci-dessous depuis l'application depuis votre téléphone.

option 3: copiez-collez manuellement le secret directement dans l'application.

Adresses qui reçoivent mes cycles


Vos cycles sont envoyés à l'adresse de connexion et à celles de cette liste. Plusieurs adresses possibles, séparées par « ; » (5 au plus). Pour la changer, confirmez avec votre mot de passe: un mail prévient votre adresse de connexion.



N'utilisez pas d'adresse qui permet de vous identifier, du type prenom.nom@domaine.fr.









Changer mon adresse de connexion




C'est l'adresse qui sert à se connecter et à retrouver un mot de passe perdu. Un lien de confirmation est envoyé à la nouvelle adresse et un mail prévient l'ancienne: le changement n'a lieu qu'une fois ce lien utilisé.



N'utilisez pas d'adresse qui permet de vous identifier, du type prenom.nom@domaine.fr.












Changer mon mot de passe

Mes connexions

Chaque navigateur ou application connecté à votre compte a sa propre connexion. Si vous ne reconnaissez pas l'une d'elles, déconnectez-la et changez votre mot de passe. Le nom et le navigateur sont ceux que l'appareil déclare: ils aident à s'y retrouver, mais ne prouvent rien. Les adresses sont tronquées à leur réseau, et la dernière utilisation n'est mise à jour que toutes les 5 minutes.

Créer un jeton d'accès

Un jeton permet à une application ou à un script d'accéder à votre compte sans votre mot de passe, en l'envoyant dans l'en-tête Authorization: Bearer. Il est affiché une seule fois, à la création. Choisissez « lecture seule » pour un script qui ne fait que lire vos données. Pour créer un jeton, confirmez avec votre mot de passe.

✅ Jeton créé. Copiez-le maintenant: il ne sera plus affiché.
